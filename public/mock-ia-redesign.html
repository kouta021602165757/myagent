🗺 IA 比較 — 旧構造 vs 新構造

旧構造ではサイドバーが「エージェント = チャット」前提で 1 列に詰まっていた。 グループ機能で複数人参加が増えるので、「会話」と「エージェント管理」を分離。 新規アクションは ⊕ ボタンに集約してノイズを消す。

📜旧構造 (今のサイドバー)

すべてが 1 列に並ぶ。トーク数が増えると新規ボタンがスクロール位置によって見えなくなる。

  • [+ 新規エージェント]
  • [📋 テンプレート]
  • [🏪 Agent Store]
  • ──────────
  • 💬 営業データ管理君
  • 💬 デザイン補佐
  • 💬 議事録さん
  • 💬 リサーチャー
  • …さらに増えるとボタンが埋もれる

✨新構造 (タブ + ⊕)

常時固定の ⊕ ボタン から 4 種の新規アクション、タブで「会話/エージェント」を切替。Slack/Discord の慣れたパターン。

  • [＋ 新規] ← 常時固定
  • 🤝 グループを作成
  • 💬 AI と DM
  • 📋 テンプレート
  • 🏪 Agent Store
  • 🛠 ゼロから作る
  • ──────────
  • [💬 トーク] [🤖 Agents]
  • トーク = グループ + DM 一覧
  • Agents = AI 管理 + 作る 3 ボタン
🎯

中央集約

⊕ ボタンが「すべての新規」のエントリポイント。覚えるのは 1 つだけ。
