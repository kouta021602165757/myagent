# FOUNDER 100 — 拡散コンテンツパック (X + TikTok)

scarcity 機構 "Founder 100" を 7 日間で売り切るための X + TikTok 専用コンテンツ。

最終更新: 2026-05-11
動画素材: `assets/founder100-vertical.mp4` (1080×1920 / 17 秒 / 850 KB / 字幕焼き込み済)

---

## 🎯 戦略 概要

Founder 100 を 7 日で売り切るための 3 段 funnel:

1. **Launch (Day 0-1)**: 「100 founders. That's it.」で scarcity を立ち上げ
2. **Countdown (Day 2-5)**: 残席が減る様子を *実数で* 連投 → FOMO 加速
3. **Closing (Day 6-7)**: 「Last 10」「Last hour」で押し切る

X と TikTok は **役割が違う**:

| プラットフォーム | 役割 | 主要メッセージ |
|---|---|---|
| **X** | conversion (signup へ直リンク) | 残席数 + Founder badge の社会証明 |
| **TikTok** | reach (新規 audience 接触) | scarcity 動画でフックして profile bio へ |

両方とも同じ Founder 100 動画を使えるが **caption / hook が違う** ので別パック。

## TikTok hashtag rotation

固定ベース (常に入れる): `#AItools #SaaS`
ローテーションプール (動画ごとに 3-4 個):
- 高 volume: `#BuildInPublic` `#IndieHacker` `#AI` `#StartupLife`
- ニッチ: `#ChatGPTalternatives` `#NoCode` `#Productivity` `#TechTok`
- イベント: `#LastChance` `#FOMO` `#Founder`

**禁止**: 関連の薄い大量ハッシュ (`#fyp` `#viral` 等) は逆効果 — algorithm が判定誤る。

## TikTok 投稿時間 (US/EU 向け)

- **Best**: PT 11:00am - 1:00pm (US 西海岸ランチ / US 東海岸午後 / EU 夕方)
- **Second**: PT 6:00 - 8:00pm (US 全土夜 / EU 朝)
- **Avoid**: PT 深夜 (US 早朝 / EU 真夜中)

JST 換算:
- PT 12:00pm = JST 04:00 翌日 (深夜 — scheduling tool 必須)
- PT 19:00pm = JST 11:00 (翌朝, 手動 OK)

# 📊 計測

- X: ImpressionsとLPクリック数を tweet ごとに Tweet Analytics で取る
- TikTok: View / Like / Follow / Bio link click を Analytics タブで
- LP 到達後の signup attribution は **`/admin-marketing.html`** で UTM 別に確認
- **TikTok bio link** には専用 UTM を:
  ```
  https://myaiagents.agency?utm_source=tiktok&utm_medium=bio&utm_campaign=founder100
  ```
- **X tweet 内 link** には:
  ```
  https://myaiagents.agency?utm_source=x&utm_medium=organic&utm_campaign=founder100-NN
  ```

NN は post 番号 (#X1 = 01, #X2 = 02, ...) で post 単位の効果計測ができる。
