## How to use this file

Each variant has a different angle. Don't dump all 8 at once — pick the
right one for the moment:

| When | Use variant |
|---|---|
| Launch-day pinned tweet on personal account | **#1 (hook)** or **#5 (founder voice)** |
| Pinned tweet on brand account @MYAIAGENT | **#4 (anti-chatbot)** |
| ProductHunt launch day reply / quote | **#7 (founder offer)** |
| Daily X post (via autopilot or manual) | rotate #2 / #3 / #6 |
| Replying to a tweet about "I have N ChatGPT tabs" | **#5** or **#6** |
| Opening a thread for a longer write-up | **#8 (thread starter)** |

All char counts include the trailing URL. Attach `demo.mp4` natively
(don't link to it) — X consumes no chars for native video. URL line at
the bottom keeps the link clickable in the body.

## What NOT to write

- ❌ "Game-changing AI assistant" — both words are dead
- ❌ "Unlock the power of AI" — pure marketing-deck noise
- ❌ "10x your productivity" — instant bot-suspicion
- ❌ "Hey 👋 indie hackers!" — the hand-wave emoji crowd has filtered this out
- ❌ Tagging unrelated big accounts (@elonmusk, @sama, @paulg) — kills your reach
