# MY AI Agent — 30 秒 Team Huddle デモ動画スクリプト

**目的**: X (Twitter) で Pin する自己紹介動画。CTR 重視 = **3 秒で「なんかすごい」と思わせる** こと。

**形式**: 画面録画 + テロップのみ (顔出し / ナレーション無し)。BGM はオプション (無音でも刺さる構成にする)。

**長さ**: 28–32 秒

---

## 撮影前準備

### 1. アカウント状態
- ブラウザに `https://myaiagents.agency/` を 1920×1080 でフルスクリーン
- ログイン済 (Founder 80–95 席残あたりの段階で撮ると緊迫感が出る)
- Chrome、シークレットモードで他タブ無し、Bookmark バー非表示

### 2. 既存エージェント
撮影アカウントに **4 名の Team** を事前に作っておく:
- **PM AI** (avatar 📋, persona "Growth Squad の進行役")
- **Marketing AI** (avatar 📈, persona "コピーライティングと SNS")
- **Designer AI** (avatar 🎨, persona "LP デザインと配色")
- **Engineer AI** (avatar ⚡, persona "A/B テスト実装")

チーム名: **Growth Squad**

### 3. 録画設定
- macOS `Cmd+Shift+5` / QuickTime / Loom / Riverside で 30fps、1080p
- カーソルは大きめハイライト (DemoPro / Cleanshot 推奨)
- 文字テロップは**画面下中央**に固定、半透明黒背景
- フォント: 太め (Inter Bold / Hiragino UD Sans 太字)

## 撮影のコツ

### Do
- ✅ **無音 / 字幕中心**: X はミュート再生がデフォルト。音に依存しない構成
- ✅ **カーソル動き最小**: 1 つのアクション = 1 つのカーソル動き
- ✅ **3 秒で核を伝える**: 「ChatGPT は質問。これは雇う」だけで OK
- ✅ **最後の 3 秒で URL を 2 秒以上見せる**: スクショされる
- ✅ **冒頭は引き気味**: フルスクリーンスクショじゃなく、ブラウザ全体が見えるアングル

### Don't
- ❌ **顔出し / ナレーション**: 個人開発者にとって心理的障壁。後で別バージョン作れば良い
- ❌ **テロップ詰めすぎ**: 1 シーンに 1 テロップが上限
- ❌ **BGM 派手**: ローファイ or 無音で OK
- ❌ **長く**: 30 秒で抑える。35 秒超えたら Twitter のレコメンドが落ちる

### Tools
- 録画: macOS `⌘+⇧+5` / Cleanshot X / Riverside / Loom
- 編集: CapCut (無料・速い) / Final Cut / Premiere
- 字幕: CapCut が AI 字幕自動生成。手で修正
- 書き出し: 1080×1920 縦長 (Twitter フィード対応 + Reels / Shorts 流用) **or** 1920×1080 横長 (LP / YouTube 埋込用)

両方撮るのが理想だけど、最初は **縦 1080×1920** だけで OK (X 縦動画は表示面積が大きく圧倒的に有利)。
