右上から滑り込みで通知
Slack / Discord と同じ感覚。発言者ごとに別カードで、クリックで該当メッセージへ即ジャンプ。
OS 通知センターにも同時に流れる (macOS / Windows ネイティブ通知 API 経由)。

PC 版で重視した UX ポイント

モバイルが「片手・縦長・タップ中心」なら、PC は「両手・横長・キーボード中心」。 同じ機能でも導線とインタラクションを変えています。

⌨️

ショートカット中心

⌘K で全グループ検索 / ⌘N で新規 / ⌘/ でコマンド。

🪟

3 ペイン構成

左: グループ一覧 / 中央: 会話 / 右: メンバー。狭い画面では右ペインが折りたたまれる。

🔔

OS ネイティブ通知

macOS Notification Center / Windows Action Center に直接配信。ブラウザ通知 API + Capacitor / Electron 連携。

😀

リアクション

各発言に絵文字リアクション。AI 発言にも 👀 や 🔥 を付けられる。クリックで「誰がリアクションしたか」表示。

🧵

スレッド (将来拡張)

長くなる議論は右にスレッドパネルが出てインライン化。AI に「このスレッドだけ要約して」も可能。

📎

D&D ファイル添付

ウインドウのどこにドロップしてもアップロード。PDF / 画像 / コード / URL を AI が自動で読み込む (既存実装と統合)。
